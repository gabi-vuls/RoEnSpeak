# Pinned lock for macOS arm64 (Apple Silicon) / CPython 3.12. See requirements-macos.in for
# provenance and for why faster-whisper, ctranslate2 and the nvidia-* wheels are absent.
#
# Generated from the working .venv with `pip freeze`, then reduced to the runtime closure
# (pytest/pyinstaller/pip/setuptools/wheel and their own deps live in requirements-macos-dev.txt).
# Verified 2026-10-22 on an Apple M1 Max, macOS 26.6.2, in a CPython 3.12.9 arm64 venv:
# `pip check` clean, and the frozen RoEnSpeak-cli translates tests/fixtures/ro_sample.wav on Metal.
#
# ARM64-ONLY, and that is what fixes the build's target_arch. onnxruntime 1.31.0
# (macosx_14_0_arm64), soxr 1.1.0 (macosx_11_0_arm64) and numpy 2.5.4 (macosx_14_0_arm64) publish
# no x86_64 or universal2 macOS wheel for CPython 3.12, so a universal2 .app is not buildable from
# these pins. PySide6-Essentials/shiboken6 are universal2 and get thinned to arm64 at build time.
#
# NOTE: the PySide6-Essentials, onnxruntime and numpy wheels are tagged macosx_14_0, i.e. they want
# macOS 14 even though contracts.MIN_MACOS_VERSION (and therefore LSMinimumSystemVersion) says 13.0.
# See BUILD.md "Prerequisites (macOS)".
